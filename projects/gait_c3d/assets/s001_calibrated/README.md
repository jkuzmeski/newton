# S001 calibrated default subject

This is the tracked default static-calibration realization of the S001 base
subject. It uses CODA/Bell--Brand hip regression, per-segment marker geometry,
hallux toe endpoints, a sacrum-to-head torso calibration, three bounded
rotational torso axes, and flat-foot contacts. The source `s001_base` template
remains separate so future subjects can be rebuilt from the same base.
